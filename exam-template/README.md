# Examen-template

Kopieer deze map voor een nieuw proefexamen en hernoem de map naar de kerntaak en korte naam, bijvoorbeeld `b1-k2-marketing-communicatie`.

Vervang daarna in de bestanden:

- `{{EXAM_TITLE}}`
- `{{EXAM_CODE}}`
- `{{EXAM_SUBTITLE}}`
- `{{BRAND_NAME}}`
- `{{BRAND_CONTEXT}}`

Gebruik `PROJECT_CONTEXT.md`, `EXAM_FRAMEWORK.md` en `STATUS.md` als leidraad.
